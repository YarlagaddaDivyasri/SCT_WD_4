# To-Do Web App

## Description
This is a simple and interactive To-Do Web Application developed using HTML, CSS, and JavaScript.

The application allows users to:
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Set date and time for tasks

It helps users organize and manage daily activities efficiently.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Set task date and time
- Simple and responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
